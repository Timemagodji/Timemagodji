## 🚀 Featured Project / ไฮไลต์ผลงานเด่น

### 🩺 [Projectjob: Skin Lesion & Skin Cancer Classification AI](https://github.com/Timemagodji/Projectjob)
> **ระบบปัญญาประดิษฐ์ประเมินความเสี่ยงมะเร็งผิวหนังและรอยโรคทั่วไป 8 ชนิด ด้วย Deep Learning (ResNet50) พร้อม Gradio Web Interface**

- **สถาปัตยกรรมโมเดล:** ResNet50 Backbone ร่วมกับ Attention Mechanism และ Two-Phase Training (Transfer Learning & Fine-Tuning)
- **การจำแนก 8 กลุ่มโรค:** ครอบคลุมทั้งกลุ่มเสี่ยงมะเร็ง (Melanoma, BCC, SCC, Actinic Keratosis) และโรคผิวหนังทั่วไป (Keratosis, Nevi, Psoriasis, Tinea)
- **Web UI & Tools:** มี Web App สำหรับทดสอบผ่าน Gradio พร้อมระบบ Export โมเดลสู่ **TensorFlow Lite (TFLite)** เพื่อรันแบบ On-Device บนแอปพลิเคชันมือถือ (Flutter)
